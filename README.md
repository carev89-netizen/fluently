# Fluently

Личное приложение для изучения английского языка для русскоговорящих (уровень B1–B2).
Один самодостаточный HTML-файл: без серверов и зависимостей, весь прогресс хранится на устройстве.

**Открыть:** https://carev89-netizen.github.io/fluently/

## Установка на iPhone

1. Открыть ссылку выше в **Safari**.
2. Нажать «Поделиться» → **«На экран „Домой“»**.
3. Приложение появится на домашнем экране и будет открываться на весь экран, в том числе офлайн.

При первом нажатии на 🎙️ Safari спросит разрешение на микрофон — его нужно дать,
иначе распознавание речи не заработает.

## Что внутри

- **Слова** — 600 слов и выражений B1–B2 по 10 темам, карточки с интервальным повторением
  (упрощённый SM-2: «снова / трудно / помню», интервалы 1→3→7→14→30→60→120 дней).
  Направление EN→RU и RU→EN, озвучка английского и русского.
- **Свои слова** — добавление собственных слов; они идут первыми в очереди новых карточек.
- **Грамматика** — 15 тем с теорией на русском, блоком «типичная ошибка русскоговорящих»
  и 120 упражнениями с объяснением каждого ответа.
- **Аудирование** — 60 предложений в 3 уровнях: приложение озвучивает фразу, нужно выбрать
  из похожих по звучанию вариантов. Есть медленный пословный повтор.
- **Говорить** — 8 ролевых сценариев (54 реплики): собеседник говорит, вы отвечаете голосом,
  речь распознаётся и сверяется с образцом пословно — прозвучавшие слова зелёные, пропущенные красные.
- **Фразы и диалоги** — 8 ситуаций (106 фраз) с тренировкой произношения по кнопке 🎙️
  и 6 озвученных мини-диалогов.

Озвучка и распознавание — встроенные возможности браузера (Web Speech API), работают бесплатно.

## Технически

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: стили, логика, учебный контент |
| `manifest.json` | манифест PWA (имя, иконка, полноэкранный режим) |
| `sw.js` | service worker: страница network-first, остальное cache-first |
| `.github/workflows/pages.yml` | автодеплой на GitHub Pages при пуше в `main` |

Прогресс (состояние карточек, стрик, результаты) хранится в `localStorage` устройства
и никуда не передаётся.
